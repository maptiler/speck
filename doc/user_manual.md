# Writing standard?

- Identifiers:
  - OCD/OCE, SRS/SDD, etc.
  - Subfolders to make CODEOWNERS easier.
  - Diagrams.
- Statement, then rationale.
- EARS
  - Describe patterns.
  - Define our set of qualifying patterns.
- ASD-STE100
  - The word "shall" is permitted for requirements.
- Document templates.
- Describe diagrams in text so that AI can read it easily.
- Draw.io diagrams:
  - Line width 2 px.
  - Font size 16 px.
  - Do not change fonts.
  - Do not set white backgrounds.
  - Straight lines for architecture.
  - Curved lines for requirements.
  - Cross lines by bridging.
